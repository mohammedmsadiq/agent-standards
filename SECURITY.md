# Security policy

## Reporting a vulnerability

Please report suspected vulnerabilities privately to the maintainer rather than in a public issue. If the
repository host offers private vulnerability reporting (for example GitHub security advisories), use it. Include
the affected version, reproduction steps and impact. You will receive an acknowledgement, and fixes will be
released as patch versions.

## Scope

In scope: the `agent-standards` tool and the templates package, including path handling, symbolic-link handling,
package extraction, manifest processing and generated configuration.

The generated Markdown files are guidance for AI assistants. They reduce risk but are not a security control:
assistants may not follow instructions perfectly. Use your assistant's own permission settings for enforcement.
